# 如何读懂循环 Transformer

[English](guide.en.md) · [中文版交互图谱](https://hyfine.github.io/loop-transformer-atlas/?lang=zh) · [六类方法详解](routes.zh.md)

## 从一次预测说起

给定一段文字，问题是“这本书作者的老师是谁？”第一遍可能把“书”与“作者”关联起来，第二遍再利用更新后的表示找“作者的老师”。这只是帮助理解的例子，**不是**“一层注意力等于一步推理”的断言。模型也不必在两遍之间把作者姓名写成 token。

普通模型依次执行不同的层：`A → B → C → D`。块循环可以执行 `A → B → A → B`，逐层循环则是 `A → A → B → B`。后两者都只存两组权重、都执行四层，但通常不是同一个函数。循环块也可以夹在不共享的前后段之间：

```text
e = P(x)                         输入只编码一次
h[r+1] = Fθ(h[r], e, r)          更新状态；跨轮共享 θ
y = head(C(h[R]))                在选定深度读出
```

这是对照不同方法的记号，并非所有模型的实现。初态可以来自输入或噪声；轮次编码、每轮重新注入输入都是选项；逐深度适配器则会放松严格的权重共享。若前段、中间共享块、后段各有 `p、b、c` 层，中间块访问 `R` 次，则**独立层数为 p+b+c，执行层次为 p+Rb+c**。第一遍也算一次：“额外循环一次”就是 `R=2`。[SenseNova 的配置](https://huggingface.co/sensenova/SenseNova-Loop-9B/blob/main/config.json)是可核对的实例：独立层数 `4 + 24 + 4 = 32`，执行层次 `4 + 2×24 + 4 = 56`。单凭这组数字算不出每秒生成多少 token。

## 技术史：研究问题是怎样改变的

| 时期 | 新问题和代表作 | 读者应分清什么 |
|---|---|---|
| 2016–19 | [ACT](https://arxiv.org/abs/1603.08983) 先在 RNN 中学习单个输入需要多少内部步骤。[Universal Transformer](https://arxiv.org/abs/1807.03819) 将共享的注意力与状态变换沿深度展开；[循环堆叠](https://ojs.aaai.org/index.php/AAAI/article/view/4590)则问：固定复用能把翻译模型压小到什么程度？ | 共享权重不等于自适应停止。[ALBERT](https://arxiv.org/abs/1909.11942)就是很好的对照。 |
| 2020–24 | [RNGTr](https://aclanthology.org/2021.tacl-1.8/) 把上轮预测的图送回解析器。理论路线区分了[手工构造的解释器](https://proceedings.mlr.press/v202/giannou23a.html)能运行什么，以及[训练出的模型](https://arxiv.org/abs/2311.12424)能从上下文中学会什么。[Sparse UT](https://aclanthology.org/2023.emnlp-main.12/) 和 [MoEUT](https://arxiv.org/abs/2405.16039) 借助稀疏专家增加存储容量，而不必让每个 token 激活全部专家。 | 反馈对象既可以是图，也可以是潜向量。可表示性证明不等于训练配方。 |
| 2024–25 | [长度泛化](https://arxiv.org/abs/2409.15647)把步数与算法难度联系起来。[Relaxed Recursion](https://arxiv.org/abs/2410.20672) 改造已有权重，[Huginn](https://arxiv.org/abs/2502.05171v2) 训练一个深度可调的检查点，[MoR](https://arxiv.org/abs/2507.10524) 则按 token 分配访问次数。 | 为每个请求选一个预算，与在一次请求内决定哪些 token 再算一轮，不是同一决策。 |
| 2026 年前三季度 | [免训练循环](https://arxiv.org/abs/2605.23872)将冻结块的一次更新拆成多个小步。[LoopCoder-v2](https://arxiv.org/abs/2606.18023) 改写位置间的依赖。[Loopie](https://arxiv.org/abs/2607.16051v3) 与 [SMELT](https://arxiv.org/abs/2609.01343v3) 各自构建不同的等预算对照。[LoopWM](https://arxiv.org/abs/2606.18208v1) 将内部深度用于细化世界模型的一次转移。 | 只有先指明**固定哪种预算**，“增加轮次是否有用”才是可检验的问题。 |
| 2026 年 10–11 月 | [SenseNova](https://github.com/OpenSenseNova/SenseNova-Loop) 的十月预览版与十一月正式版是两个事件。[Dory](https://arxiv.org/abs/2611.03998) 保存最后一轮历史，[GLM-5.4](https://z.ai/blog/glm-5.4) 披露“全局共享、局部保留”，[MoLT](https://arxiv.org/abs/2611.34923v1) 则研究直接用 KV 传递跨轮信息。 | 工程问题不只是“循环几次”，而是“下一轮能读哪个位置的什么状态，要付出多大代价”。 |

## 六类方法，四个独立设计轴

[家族树](https://hyfine.github.io/loop-transformer-atlas/?lang=zh#tree)为每项工作选一个主要入口，并非互斥分类。Dory 既是预训练模型，也有缓存设计；放在执行路线，是为了便于与其他服务方案比较。

| 路线 | 要问的问题 | 代表案例 |
|---|---|---|
| A · 共享与算法 | 算子是构造出来还是训练出来？它能辨别自己处于第几轮吗？ | [UT 与算法任务对照](routes.zh.md#route-a) |
| B · 循环核预训练 | 状态如何初始化、如何重新读取输入、如何保持稳定？ | [Huginn 与逐层循环的 Loopie](routes.zh.md#route-b) |
| C · 自适应深度 | 是调用者、停机概率，还是 token 路由器在分配预算？ | [Mixture-of-Recursions](routes.zh.md#route-c) |
| D · 存量模型改造 | 冻结模型、只学小修正，还是沿新路径继续训练？ | [阻尼子步与可训练门控](routes.zh.md#route-d) |
| E · 调度与缓存 | 哪些依赖可重叠执行？哪些轮次的 KV 必须保留？ | [LoopCoder-v2、Dory 与 LoopCache](routes.zh.md#route-e) |
| F · 结构化状态 | 在环境或模拟时间前进之前，究竟细化了什么？ | [图、动作与世界状态](routes.zh.md#route-f) |

遇到新论文，建议先写四个字段：**共享粒度**（整栈、中间块、单层、子层）；**反馈对象**（残差状态、条件输入、图或 KV）；**权重来源**（从头训练、继续训练、适配器、冻结）；**预算策略**（固定、训练时采样、推理时指定、按数据决定退出）。比如“冻结权重／中间块／阻尼状态反馈／固定子步”就比笼统地称为“潜空间推理”更有辨识力。

## 四组不应塞进同一排行榜的实验

| 来源与实际控制变量 | 观察结果 | 不能推出什么 |
|---|---|---|
| [Huginn 表 1](https://arxiv.org/html/2502.05171v2)：同一个 3.5B 检查点，训练了 0.8T token，只改推理深度。 | 4、8、16、32 轮的 ARC-Easy 依次为 **49.07、65.11、69.49、69.91**。最后一次翻倍只多 0.42 分。 | 不能推出通用最优轮数，也不能把它当成拥有 50B 参数的知识库。表 4 的固定深度基线只有 0.18T 训练 token。 |
| [LoopCoder-v2 表 2](https://arxiv.org/html/2606.18023v1)：指令微调条件匹配，但不同轮数是**分别训练**的模型。 | SWE-bench Verified 在 1、2、3 轮分别为 **43.0、64.4、27.6**。作者将回退解释为细化收益变小而位置错位代价仍在。 | 这不是 Huginn 那种单检查点推理扫深度，也不是所有模型都有两轮上限。 |
| [Loopie 第 3 节、表 1](https://arxiv.org/html/2607.16051v3)：匹配优化器单步实测耗时、token 预算和更新次数，同时调批量与并行配置。 | 共享后可用更大微批；选中方案的理论块计算量代理是参考模型的 **1.42 倍**。 | 等训练耗时不是等理论 FLOPs；该结果也没有证明解码延迟相等。 |
| [SMELT 扩展实验](https://arxiv.org/html/2609.01343v3)：对不同稀疏 MoE 设计尽量匹配每 token FLOPs、非嵌入参数和 KV。 | 拟合的计算最优前沿显示，在所比较的损失水平上训练算力可少用 **6.8%–18.0%**。 | 不能解读成任意模型实测墙钟时间都缩短相同比例。 |

**怎样自己检验？** 固定提示集、分词器、输出策略、批量、精度和硬件；记录质量、输出 token 数、预填充耗时、每 token 解码耗时、延迟分布、峰值内存及持久 KV 字节数。深度可变时公布直方图，不只报均值。对非共享模型分别做等存储参数与等算力两种比较：它们回答的问题不同。

## 三种常见失败，以及一个范围边界

- **多算反而改错答案。** 状态可能漂移或振荡。应检查各轮读出与强制提前退出的结果；状态变化很小也不证明答案正确。[LoopCoder-v2](https://arxiv.org/abs/2606.18023) 给出了非单调的实测反例。
- **冻结块第二次收到分布外输入。** 若 `F(h)=h+Δ(h)`，直接再执行一遍便多走了一个完整步长。阻尼欧拉改为 `h ← h + αΔ(h)`，每步重算位移。ODE 类比启发了包装器，却没有证明所有层都是连续流。[免训练论文表 2–3](https://arxiv.org/abs/2605.23872)。
- **共享权重不等于共享激活。** 同一历史 token 两次访问得到的 K/V 可以不同。共享或丢弃某一轮的缓存，会改变后续 token 可读取的信息。对照 [Dory](https://arxiv.org/abs/2611.03998)、[LoopCache](https://arxiv.org/abs/2611.24301) 与 [MoLT](https://arxiv.org/abs/2611.34923v1)。
- **“有循环”不等于循环深度。** 多生成思维链 token 是沿序列加长；共享核是在一次预测内部沿深度迭代。智能体的计划—执行循环、环境时间的递推，都在该次预测之外。混合系统应标出两条轴，不能凭产品输出倒推其内部架构。
